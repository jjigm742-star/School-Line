# 🎴 카드클래시 2.5 — GitHub + Render 통합게임

원본: 《카드클래시 1.0》 72종 GitHub 통합게임. 2.5는 84종(기존 밀물·썰물 통합 + 신규 5종), 기본 덱 30장(카드당 최대 3장)입니다.

## 플레이 모드

- `/` : 메인 화면 / 플레이 모드 선택
- `/solo.html` : 혼자 양측을 직접 조작하는 플레이(컴퓨터 AI가 아닙니다). 드래그, Undo, 저장·불러오기 지원.
- `/online.html` : 실제 플레이어 2인 온라인 대전. 6자리 친구 방 또는 자동 매칭. 각자 자기 패만 표시.
- `/admin.html` : 서버 밸런스 관리자(설정한 관리자 토큰이 필요).

## 2.0 기반 구성 (2.5에서 조정된 카드 포함)

- 랜드: 황소(70/1500/돌파1), 철갑 코끼리(180/3500/공격 대상 지정 시 턴당 1회 ATK +500)
- 오션: 청새치(75/2000/고속), 흉폭한 크라켄(175/3500/돌파1)
- 스카이: 악랄 알바트로스(60/1000/강타2), 벌새(175/1500/러시, 저공격력 스카이 2장까지 덱 특수 소환)
- 아더스: 묘지기(80/2000/묘지 기술 1장 회수 리액션), 마녀여왕(185/2500/B라인 아더스 전체 파워 +500, 25E로 묘지 스켈레톤을 A라인에 반복 부활)
- 비용 인하: 안경 원숭이 25ME, 흰동가리 20ME, 둔한 펭귄 85ME, 저주받은 책 45ME.
- 화산 분출 75TE: 양측 덱 1장씩 소진, 리액션 패 회수 유지.
- 일석이조 125TE: 패/묘지에서 기본 ATK 1000 이하 스카이 몬스터를 **각각 정확히 1장** 특수 소환. 일반 발동은 A라인, 리액션은 B라인. 두 구역 모두 적합한 대상이 반드시 존재하며 해당 라인의 빈 공간 2칸 이상 필요. 조건 미달 시 0장 소환.
- UI/UX: ATK 증감 출처/순서, 유발효과 출처, 묘지 클릭 확인, 공격 덱 소진 시 시각 피드백.

## 기존 GitHub·Render에 2.5 반영하기

1. 기존 2.0 파일을 먼저 로컬에 백업합니다. **현재 운영 중인 동일한 GitHub 저장소**에서 변경된 파일 `app/solo.html`, `app/online.html`, `app/index.html`, `app/admin.html`, `app/decks.js`, `server.py`, `README.md`, `tests/test_2_5_engine.py`를 갱신합니다. 나머지는 보존합니다.
2. 기존 GitHub 저장소의 대상 브랜치에 변경 내용을 반영하면, **현재 연결된 Render 서비스**의 기존 배포 설정에 따라 새 커밋이 배포됩니다. 새로운 Render 서비스 또는 저장소를 만들지 마세요.
3. 기존 `Dockerfile`, `requirements.txt`, `render.yaml`은 그대로 사용합니다. Render 서비스 이름도 기존의 `cardclash-2-0`을 유지합니다.
4. 배포 후 `/api/health`가 `version: 2.5`를 반환하는지 확인하고, 혼자 대전과 친구 방 대전을 각각 테스트합니다.

※ 대전 중이던 방과 구버전 게임 저장은 유지되지 않을 수 있습니다. 덱 라이브러리는 각 브라우저 로컬 저장이며 다른 기기로 자동 동기화되지 않습니다.


## 2.5 반영 및 이름별 다중 덱 (2026-11-07)

- **기존 GitHub/Render/Docker 웹서비스 구조를 유지**합니다. 새 앱이나 서버 구조를 만들지 않습니다.
- 카드 84종: 기존 밀물·썰물을 `밀물 썰물` 1종으로 통합, 신규 스켈레톤·생명의 우물·파이어 트랩·깃털·정어리.
- 긴급 출항 95E·파워 +1000, 티타늄 산호 85G, 청새치 75G, 물결 고래 120G. 방어벽 리액션 패 회수. 마녀여왕 기존 TE +50 유발 제거, 묘지 스켈레톤 25E 반복 부활.
- 덱 관리: 무에서 시작해 이름 붙이기, 여러 덱 만들기, 좌우로 한 덱씩 넘기기, 복제, 이름 변경, 삭제 확인, 30장 완성 시 대전용 선택.
- 덱 출력: 현재 덱 카드명과 매수만 담은 UTF-8 TXT 내보내기. JSON 백업/가져오기 기능도 제공.
- 1인/온라인 덱은 동일 출처의 브라우저 localStorage를 공유합니다. 기존 2.0 종족별 커스텀 덱을 처음 한 번 자동 변환합니다(변환 불가능한 설정은 기본 덱으로 보정). 기기를 바꾸면 파일로 옮겨야 합니다.
- **주의**: 명명된 덱은 사용자 브라우저에 저장되며 서버에는 덱 영구 보관 기능이 없습니다. 온라인 입장 시 30장 덱 데이터를 서버에 전송해 검증합니다.
- 기존 2.0 게임 저장 JSON과 새 2.5 엔진을 호환된다고 가정하지 마세요.
