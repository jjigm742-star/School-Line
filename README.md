# School Line — Mobile Alpha 0.2

휴대폰 브라우저용 4대4 점유전 프로토타입입니다. 게임 서버 규칙은 Alpha 0.1을 유지하고, 화면과 조작을 모바일에 맞게 바꿨습니다.

## 모바일 조작

- 휴대폰을 가로로 사용합니다.
- 왼쪽 가상 스틱: 이동
- 오른쪽 가상 스틱: 조준 + 누르고 있는 동안 자동 사격/치유
- 오른쪽 스틱을 놓으면 발사가 멈춥니다.
- `가로 전체화면` 버튼은 지원되는 브라우저에서 전체화면과 가로 잠금을 요청합니다. iPhone/Safari 등 일부 브라우저는 가로 잠금을 허용하지 않으므로 직접 기기를 돌리면 됩니다.

맵은 서버 좌표를 바꾸지 않고 화면에서만 90도 회전해서 보여줍니다. 모바일에서는 A팀 진영이 왼쪽, B팀 진영이 오른쪽입니다.

## 게임 규칙

- 최대 8명, 자동 A/B 팀 배정
- 3분 단판
- 상대 소유구역에 우리 팀 1명 이상, 상대 팀 0명이면 초당 1점
- 사망 후 5초 뒤 풀 HP 부활
- 캐릭터 중복 선택 허용
- 첫 입장자가 방장

## 캐릭터

- 아이언: HP 600 / 속도 4.0 / 큰 피격판정 / 65 DPS / 초당 5발 / 느린 중간탄
- 슈터: HP 250 / 속도 5.0 / 중간 피격판정 / 100 DPS / 초당 5발 / 빠른 작은탄
- 캐논: HP 275 / 속도 3.2 / 큰 피격판정 / 140 DPS / 초당 10발 / 빠른 중간탄
- 파이어: HP 200 / 속도 6.0 / 중간 피격판정 / 80 DPS / 초당 5발 / 빠른 작은탄 / 10 DPS 화상 2초
- 워터: HP 250 / 속도 5.0 / 작은 피격판정 / 65 HPS / 초당 5발 / 보통 작은 치유탄 / 공격 없음
- 윈드: HP 225 / 속도 6.0 / 작은 피격판정 / 55 HPS / 초당 5발 / 보통 큰 치유탄 / 순풍 2초 / 공격 없음

## 인터넷에서 휴대폰 여러 대로 플레이하려면

이 프로젝트는 `PORT` 환경변수를 지원하고 HTTPS 페이지에서는 자동으로 `wss://` WebSocket을 사용하므로 일반적인 Node 웹 호스팅에 그대로 배포할 수 있습니다. `Dockerfile`과 `render.yaml`도 포함했습니다.

서버가 인터넷에 올라간 뒤에는 학생들이 설치 없이 배포 주소를 Chrome/Safari/Edge에서 열면 됩니다. 별도 앱 설치나 Node.js 설치는 학생 휴대폰에 필요하지 않습니다.

## 로컬 테스트

Node.js 18+가 있는 컴퓨터에서는:

```bash
node server.js
```

그 후 같은 네트워크의 휴대폰에서 `http://컴퓨터IPv4:3000`으로 접속합니다.

## 파일 구조

- `server.js`: authoritative 게임 서버
- `public/index.html`: 모바일 UI
- `public/game.js`: 듀얼 스틱 입력, 네트워크, 회전 렌더링
- `public/style.css`: 가로 전체화면 UI/가상 조이스틱
- `Dockerfile`, `render.yaml`: 인터넷 배포용 설정
