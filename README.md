- 버퍼 링크를 받는 아군에게만 **16m/궁극기 중 24m 범위 원** 표시.

# 《스쿨라인》 1.14 — 시스템 1단계 경량 배포본

이 ZIP은 **전체 플레이 기능과 캐릭터 29종을 유지**하면서, 기존 102개 파일을 줄인 경량 배포용 패키지입니다. 1.13 캐릭터별 공격력·체력·스킬 수치는 그대로이며, 블레이드 궁극기는 **용검**, 참격은 **무기를 들지 않은 상태에서 붉은 판이 좌↔우 왕복하는 연출**입니다.

## 경량화 방식

- 캐릭터 일러스트 29장 → `public/assets/characters/portrait_atlas.webp` **1개**
- 기본 미니미 29장 + 스킨 미니미 5장 → `public/assets/characters/token_atlas.webp` **1개**
- 게임과 직접 관계없는 다른 앱, 레거시 서버, 이전 테스트·개발 문서는 배포본에서 제외
- 기존 패치 기록 `1.10.json`, `1.11.json`, `1.12.json`, `1.13.json`은 통계·히스토리 연속성을 위해 **보존**

캐릭터 선택창, 일러스트 확대 보기, 인게임 미니미는 공통 이미지 시트에서 정확한 영역을 잘라 표시합니다. 캐릭터의 HP·데미지·스킬 쿨타임은 기존 1.13과 동일하며, 치유 감소 적용 대상과 이동속도 계산 방식만 1.14 체계로 변경됩니다.

## 궁극기 시각효과 — 1.13 최종

- 서버의 **실제 궁극기 발동 성공**이 확인되면 시전자 본인의 화면에만 궁극기 이름·짧은 화면 가장자리 발광을 약 0.5초 표시합니다. 다른 플레이어와 관전자에게는 해당 화면 연출이 전달되지 않습니다.
- 다른 플레이어도 확인할 수 있는 전장 연출은 별도로 추가했습니다. 블레이드 용검의 진홍색 잔광과 강화 참격(무기 없음), 엔젤 기적의 무적 대상 후광, 스타 슈퍼노바의 실제 폭발 시점 황금별, 레스큐 골골대기의 분홍색 발바닥이 대표적입니다.
- 아이언·메카·아이스·스타의 지연형 궁극기 폭발 위치·타이밍은 **서버 확정 이벤트**로 표시합니다. 기적·만개의 효과는 시전자가 아니라 실제로 선택된 대상에게 적용됩니다.
- 나머지 궁극기도 캐릭터별 고유 색상·도형·지속 잔광을 강화했습니다. 별·발바닥·눈송이 같은 문양은 게임플레이의 원형 타격 판정과 무관한 **시각 장식**입니다.
- 효과는 HTML/CSS와 Canvas로 그려 **별도 이미지 파일 없이** 기존 공통 Canvas/HTML 기반 그래픽 구조를 유지합니다.
