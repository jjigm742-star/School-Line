## 1.11 변경사항

- **경쟁전 랜덤 맵:** 《교실》과 《운동장》을 서버가 **밴·픽 전에 50:50**으로 결정. 밴·픽 화면에서 맵 이름과 미니맵 공개. 해당 경기 종료까지 고정. **일반전은 기존 《교실》 유지.**
- **운동장:** 68×42m, 기존 교실의 중앙 6×6m 장애물만 제거하고 나머지 6개 벽 유지. 서버 이동·LOS·투사체·제트 돌진·마그넷 당김·스프레이 측면 발사와 클라이언트 화면 모두 같은 `room.mapId`를 사용.
- **힐팩:** 운동장의 중립 지역 상단/하단 서버 좌표 `(x=3,y=34)`, `(x=39,y=34)` 각 1개. 부족한 체력에 최대 100HP 회복, 20초 뒤 재생성, 접촉 시 자동 획득. 적/아군 모두 획득 가능, 보호막과 궁극기 충전 없음. 치료 전면 차단 상태에서는 회복하지 않으며 힐팩을 소비하지 않음. 접촉 범위는 피격 반경+힐팩 반경 0.8m. **힐팩도 기존 치유 차단 규칙을 따름.**
- **쉴드:** HP 450→400, 일반 스킬 보호막 175→150. 궁극기 유지.
- **파이어:** 기본 DPS 80→70 (발당 16→14); 화상·궁극기 유지.
- **마그넷:** 자석 스킬 투사체 속도 28→42; 일반 공격 및 쿨타임 유지.
- **통계:** 경기 원본에 `mapId`/`mapName` 추가, 통계 고급 분석에 맵별 픽·밴·캐릭터 승패 추가. 기존 맵 기록이 없는 과거 경기는 `unknown`으로 별도 분류하여 오기록 방지.
