# 스쿨라인 1.8 — 레이저·라이트 궁극기 방향 동기화 및 버퍼 HPS 표시 검증

**기준:** `School_Line_1.8_Official_Release.zip` (정식 1.8 원본은 변경하지 않음)

## 수정

1. 레이저 「파괴광선」 및 라이트 「스포트라이트」는 기본 공격 입력 `fire`와 관계없이 궁극기 버튼이 눌린 순간의 총구 방향으로 발동한다. 클라이언트는 단위 조준 벡터 `aimDirX` / `aimDirY`를 궁극기 메시지에 함께 보내며, 서버는 값의 유효성을 검사하고 정규화해 해당 시전 방향으로만 직사각형 판정을 만든다. 이전 버전 클라이언트와의 호환성을 위한 기존 조준 좌표 폴백은 유지한다.
2. 모바일 조준 스틱을 놓아도 마지막 조준 방향을 유지하며, 게임 상태 스냅샷이 들어올 때마다 조준 방향을 팀 시작 방향으로 초기화하던 문제를 수정한다. 모바일 입력 메시지의 조준 목표를 이동하는 플레이어 위치 기준으로 재계산하여 이동 중에도 총구 방향을 유지한다.
3. 버퍼의 실제 기본 링크 치유 및 서버 설정값은 원본 1.8부터 **40 HPS**, 궁극기는 **65 HPS**였다. 클라이언트 캐릭터 선택/상세/설명 화면도 서버에서 받은 `linkHealHps` 또는 40 HPS 설명 문구를 사용함을 확인했다. 구형 JS 캐시를 강제로 재검증하도록 `game.js` URL을 버전 처리했다. **표시를 서버와 독립적으로 강제해 실제 45 HPS를 은폐하는 코드 변경은 하지 않았다.** 만일 45가 계속 보이면 현재 실행 서버가 다른 배포본인지 확인해야 한다.

## 변경 범위
- 게임 플레이: **레이저와 라이트의 방향 처리만** 변경. 궁극기 효과·피해·치유·충전량·지형 관통·버퍼 치유량 자체는 변경 없음.
- 변경 파일: `server.js`, `public/game.js`, `public/index.html`, 신규 테스트 1개, 이 문서.
- 계정 및 통계 데이터, 데이터베이스 스키마, 다른 캐릭터 밸런스 수치에 변경 없음.

- `node tests/ultimate_aim_hotfix_selftest.js`
- `npm run test:ult`, `npm run test:heal-pierce`, `npm run test:1.8.2`, `npm run test:light-buffer`, `npm run test:1.8-release`, `npm run test:stats`
