# 《스쿨라인》 1.9 — 신규 캐릭터 4종 정식 소스 빌드

## 빌드 및 데이터 정책

- 베이스: 제공된 `School_Line_1.8_Curse_Status_Additive_Mitigation(1).zip` (1.8 + 사전 구현된 독립 저주 상태이상).
- 게임 버전: **1.9**, npm 패키지: **1.9.0**, 경쟁전 로스터: **26종** (`1.9-release-roster-26`).
- **26종 전체 게임**이며 기존 캐릭터 22종의 전투/궁극기 구현을 유지한다. 변경된 기존 밸런스는 **아이언·쉴드·메카 DR 10% → 0%**뿐이다.
- 제공한 4개 캐릭터 카드를 직접 자르고 가공해 `public/assets/characters/<id>/portrait.webp`와 투명 배경의 `token.webp`로 등록했다. 캐릭터 소개 화면의 스토리 텍스트와 특성/궁극기 설명도 등록했다.
- **1.9 후속 시각 보정:** 26종 전체 선택창/확대보기 portrait를 캐릭터별 개별 크롭으로 재정리해, 설명문·미니미가 portrait 안에 섞이지 않도록 수정했다. 썸네일과 확대보기는 동일한 일러스트 전용 자산을 사용한다.
- `data/` 폴더(계정 seed 포함)는 배포 ZIP에 **포함하지 않는다.** 기존 서버의 운영 데이터나 PostgreSQL 데이터를 삭제·대체하지 말 것. `DATABASE_URL`이 설정된 PostgreSQL이 계정, PIN, 경기 및 통계의 영속 저장소다. 이 ZIP을 만드는 과정에서 서버/DB/호스팅에 접근·배포하거나 통계를 삭제하지 않았다.
- 경쟁전 통계 시리즈는 기존 1.7/1.8 자료와 독립적인 **1.9**로 새로 구분된다. 과거 원본 경기 기록은 보존하며 새 26종 로스터를 경기별로 기록한다. 기존 경기의 참여 캐릭터 수를 26으로 재작성하지 않는다.

## 새 캐릭터

### 위치 (Witch) · 탱커

HP 500 / 이속 5.0 / 큰 피격판정 / 광선 16m 70 DPS.

- 「저주」: 지정 적 1인 / 거리·시야 제한 없음 / 쿨다운 10초(즉시 시작) / 5초 피해증가 +25%p. 비중첩. 기존 DR과 합연산으로 계산. 기본 공통 저주 상태이상에는 고정 지속시간이 없다.
- 「마법약」: 1400 충전. 위치를 따라다니는 반경 16m 경고 2초 뒤 발동 시점의 위치를 중심으로 모든 적에게 저주 5초와 이속 -1단계 5초. 경고 중 사망하면 실패하지만 충전량은 반환하지 않는다. 궁극기 충전 7초 제한.

### 해커 (Hacker) · 딜러

HP 225 / 이속 7.0 / 중간 피격판정 / 공격 12m·빠름·보통 크기·5발/s·발당18 (90 DPS).

- 「은신」: 쿨다운 12초(즉시 시작) / 4초. 상대에게만 캐릭터 본체 렌더링 숨김, 아군은 정상, 본인에게는 반투명 전용 표현. 공격해도 은신 해제되지 않으며 투사체는 모두 보임. 피해·충돌·점수·거점 판정 정상 유지.
- 「EMP」: 1000 충전 / 반경 16m의 적을 1초 기절시키고 현재 개인 보호막 제거 / HP 피해 0 / 이후 새 보호막 정상 / 궁극기 충전 1초 제한.

### 레스큐 (Rescue) · 힐러

HP 200 / 이속 6.0 / 작은 피격판정 / 치유탄 16m·보통 속도·큰 크기·5발/s·10 피해와 12 회복 (50 DPS / 60 HPS).

- 「긴급출동」: 쿨다운 12초(즉시 시작) / 거리·LOS 무제한 살아 있는 **다른 아군** 선택 / 해당 아군의 중심으로 즉시 이동 + 대상에게 30 HP 회복. 무적 없음.
- 「골골대기」: 1000 충전 / 즉시 반경 12m의 자신과 모든 아군에 각 75 치유. 치유하기 전 대상의 HP 부족분을 기준으로 초과량은 공통 개인 보호막(최대 500)으로 전환하고, 공통 보호막 풀에 합산되지만 레스큐가 부여한 잔여 보호막 몫은 별도로 추적하여 3초에 만료한다. 궁극기로 발생한 치유는 궁극기 충전되지 않음. 충전 제한 3초. 공통 엔진의 치유 감소로 회복되지 않은 양은 보호막으로 전환하지 않는다.

### 드레인 (Drain) · 딜러

HP 250 / 이속 6.0 / 중간 피격판정 / 공격 24m·빠름·보통 크기·5발/s·발당16 (80 DPS).

- 「흡혈」: 기본 탄환이 적 HP 또는 개인 보호막에 실제 피해를 주면 4 HP 자가 치유. 실제 유효 피해와 실제 치유량만 각각 궁극기 충전. HP가 가득 차 있으면 치유로 인한 추가 충전 없음.
- 「뱀파이어」: 1000 충전 / 즉시 HP100 회복(그 자체로 재충전 안 됨) / 8초간 공격속도 +25% / 궁극기 충전 8초 제한. 기존 버퍼 행동속도 지원과의 중첩에는 게임 공통 적용 방식을 따른다.

## 공통 시각 효과

- 위치의 마법약은 기존 분쇄의 서버 기반 경고 범위 렌더링을 재사용해 이동 중에도 중심과 반경을 갱신한다.
- 은신 해커의 본체·탄환 발사 위치에 붙는 개인 능력/사격 이펙트는 상대 화면에서 숨긴다. 탄환 자체는 계속 보인다. 관전자 화면은 정상 렌더링한다.
- 새로운 4명은 캐릭터 선택, 스토리, 일러스트 확대보기, 미니미, 전투 입력, HUD, 버전 로스터, 경쟁전 드래프트에 등록된다.

## 테스트

`npm run check`, `npm run test:1.9`, `npm run test:curse`, `npm run test:stats`, `npm run test:ult`, `npm run test:heal-pierce`, `npm run test:1.8.2`, `npm run test:light-buffer`, `npm run test:1.8-release`, `npm run test:aim-hotfix`.

기존 테스트 이름에 `1.8`이 남아 있는 것은 기존 기능의 **회귀 테스트**를 보존했기 때문이며, 1.9에서 의도적으로 바뀐 DR·버전 조건만 기대값을 변경했다. 검증은 로컬의 메모리 기반 로직 및 정적 자산 검사로 진행했다. **실제 4대4 네트워크/브라우저/운영 DB 연동 실전 검증은 별도로 필요**하다.

## 알려진 기존 엔진 제약

- 공통 개인 보호막 시스템은 원래 여러 출처의 보호막이 하나의 합산 풀/만료 타이머를 공유한다. **레스큐 신규 보호막에 한해 몫을 따로 추적해 3초 개별 만료**를 구현했다. 나머지 기존 보호막의 출처별 만료 규칙은 변경하지 않았다. 레스큐 보호막은 피해를 받으면 공통 풀에서 비례 감소한 만큼의 잔여 몫만 만료 시 제거한다.
- 은신은 상대 화면에서 캐릭터를 숨기는 클라이언트 표현 방식이다. 기존 네트워크 최적화 정책 때문에 권한별 좌표 비공개(패킷 수준의 은닉)는 이 릴리스에 포함되지 않았다.

## 배포 전 주의

정식 서비스에 배포하기 전에 실제 PostgreSQL **전체 백업**과 서버 백업을 분리 생성하고, 별도 스테이징 데이터베이스에서 경쟁전·계정 로그인·캐릭터 선택·이펙트·2팀 게임을 확인한다. 1.8 자료 삭제/초기화, 운영 DB 재생성, seed 덮어쓰기 금지. 이 ZIP은 게임 소스 아티팩트이며 실제 서비스 반영 자체는 아니다.
