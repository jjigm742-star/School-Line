SCHOOL LINE 1.8 OFFICIAL SOURCE RELEASE
==================================
Official source package version: 1.8 (package.json: 1.8.0), competitive stats series: 1.8.
Based on the isolated 1.8.2 Light/Buffer adjustment prototype, with final Dia/Iron changes.

Dia: Normal-form OR Dia-form credited kills reduce remaining Form Change cooldown by 6s; Form beam 90 -> 95 DPS.
Iron: incoming DR 20% -> 10%, projectile speed 14 -> 20m/s, Pulverize stun 1.5 -> 2.0s.
All earlier 1.8 ultimate, heal-pierce, Runner/Sniper/Shooter, Light/Buffer changes retained.
Source archive only: NOT deployed; GitHub, live service, PostgreSQL, account records, and historical match records untouched.
See README_1.8_RELEASE.md for verification and deployment precautions.

--- Original 1.7.1 source manifest (historical baseline) ---
School Line Mobile
Gameplay balance: Alpha 1.6.2 (gameplay values unchanged from the supplied authoritative build)
Competitive statistics series: 1.7 RESET
Visual asset update: 1.7.1 (illustration replacement + minimi replacement + size-class normalization)
Persistence architecture: PostgreSQL durable-only v1

Data policy:
- Historical local 1.6 aggregate stats intentionally discarded.
- No runtime competitive_stats.json.
- No runtime player_accounts.json.
- PostgreSQL is authoritative.
- Server fails closed without DATABASE_URL.

Admin stats UI:
- Available from the first join/lobby screen without joining a room.
- Fixed non-scrolling header contains JSON backup button.
- HTTP admin stats/export endpoints do not depend on game WebSocket state.
- Dynamic stats-version selector reads versions present in durable data.

Roster evolution:
- Every raw match stores availableCharacters + rosterSnapshot + rosterVersion.
- New characters only accrue availableMatches after they exist in the roster.

Visual notes:
- Server logic, statistics handling, and gameplay balance are intentionally frozen.
- 13 newly finalized character cards are now wired into portrait/token asset slots.
- Token render size is normalized by the existing small / medium / large gameplay radius classes.
- Character art URLs are versioned with ?v=1.7.1 for client cache refresh.
- 1.7.1-final: character-select portraits are cropped to show illustration only, and mecha portrait corruption is fixed.
