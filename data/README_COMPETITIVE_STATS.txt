School Line 경쟁게임 통계 데이터 안내

- 서버는 완료된 경쟁게임이 처음 발생하면 이 폴더에 competitive_stats.json을 자동 생성합니다.
- 이후 누적 패치를 기존 폴더 위에 덮어쓸 때 competitive_stats.json은 보존하세요.
- 배포 폴더를 매번 새로 만드는 경우에는 기존 competitive_stats.json을 새 버전의 data 폴더로 복사하면 누적 통계가 이어집니다.
- 배포 ZIP에는 빈 competitive_stats.json을 넣지 않습니다. 기존 기록을 실수로 덮어쓰지 않기 위한 구조입니다.

통계 기준
- 캐릭터 통계의 가장 큰 구분 기준은 '버전 번호'입니다. 현재 기준은 1.3입니다.
- 같은 1.3 번호를 유지한 채 버그 수정, UI 수정, 스토리/FX 수정, 내부 빌드 변경을 해도 모두 하나의 1.3 통계로 합쳐집니다.
- 신캐 추가 또는 큰 밸런스 조정으로 새 통계를 시작하려면 서버 코드의 BALANCE_VERSION 숫자를 올리면 됩니다.
- 번호가 바뀌어도 과거 기록은 지우지 않습니다. 예: 1.3 기록은 남고 1.4 통계가 새로 시작됩니다.
- 관리자 통계 화면에서 저장된 과거 버전 번호를 선택해 다시 볼 수 있습니다.

세부 기록
- 각 경기에는 statsVersion / gameVersion / buildId / rosterVersion / availableCharacters를 저장합니다.
- buildId와 rosterVersion은 당시 빌드를 추적하기 위한 메타데이터이며 캐릭터 통계를 나누는 기준은 아닙니다.
- 캐릭터별 availableMatches를 저장하며 밴률/픽률은 해당 버전에서 그 캐릭터가 실제 선택 가능했던 경기 수를 분모로 계산합니다.
- 승률은 해당 캐릭터가 실제 픽된 경기의 승/패만 사용하며 무승부는 승률 분모에서 제외합니다.
- 전체 경기 원본은 계속 누적 저장되므로 버전별 통계와 장기 이력을 모두 보존할 수 있습니다.

관리자 통계는 서버의 관리자 인증을 통과한 연결에서만 열 수 있습니다. 공개 /competitive-stats.json 엔드포인트는 차단되어 있습니다.
